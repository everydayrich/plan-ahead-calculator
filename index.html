Plan Ahead Calculator

Plan for the big stuff before it shows up.

A sinking fund is money you set aside a little at a time for an expense you know is coming, so the cash is ready when the bill shows up.
Pick what you're planning for, fill in a few details, and the calculator will tell you how much to set aside each month so the money is there when you need it.
